# Reza Ahmadizadeh — Portfolio

A responsive personal portfolio for GitHub Pages, featuring selected product work, course projects, teaching experience, research, education, and contact links.

## Publish with GitHub Pages

1. Push the site files to your GitHub repository. For a user site, name the repository `Teoyed.github.io`.
2. Open the repository’s **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**, then choose `main` and `/ (root)`.
4. Save and open `https://Teoyed.github.io` after deployment completes.

The project cards link to public repositories on [github.com/Teoyed](https://github.com/Teoyed). Google Fonts are used when available, with local font fallbacks.
